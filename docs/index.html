DevOps Deployment Project

A small Node.js app demonstrating Docker, Nginx and CI/CD.

About

This repository contains a simple Express API and deployment artifacts (Dockerfile, nginx.conf, GitHub Actions workflows).

API root: / — returns a JSON status object.

Health check: /health

Info: /api/info

How this site is deployed

  • On push to main, a GitHub Actions workflow publishes the contents of this docs/ folder to GitHub Pages.
  • If you want the API running, deploy the Node app to a server or platform that supports Node (Heroku, Render, Vercel, a VPS, or a container).
